Never Ask Twice

An enterprise support MemoryAgent that carries customer context across sessions, evaluated with a live re-ask-rate ablation.

A customer who has already explained their situation should not be asked to explain it again.

SESSION 01 Customer explains the plan, the dependent, the failed claim. CONTEXT WRITTEN
SESSION 04 · WEEKS LATER Agent opens with what it already knows, and asks only what changed. CONTEXT RETRIEVED
AND WHAT IT FORGETS A forgetting policy decides what stops being relevant. Memory that only accumulates is a liability in a regulated support conversation.
