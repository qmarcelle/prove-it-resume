PROOF PROGRESS
01 / OPERATING THESIS

AI agents are easy to demo. Production developer systems are harder.

Context

Agents make decisions with incomplete, stale, fragmented, or poorly surfaced repository context.

Integration

Giving an agent access to another tool does not automatically mean the tool will be considered at the right decision point.

Evidence

A successful-looking agent run is not enough. Production systems need observable boundaries, reproducible behavior, and explicit limitations.

Most of my recent work explores different parts of this boundary.
